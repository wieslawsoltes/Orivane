# Orivane 0.2

A local-first collaborative whiteboard built with plain HTML, CSS and JavaScript, WebGPU rendering with a Canvas fallback, character-level collaborative text, and an optional self-hosted workspace backend.

The Orivane 0.2 source import and GitHub Pages deployment are being prepared in this repository. The published Pages edition provides local browser editing. Collaboration, accounts, SSO and provider integrations require the included Node.js backend on a separate server; GitHub Pages does not run that backend.
